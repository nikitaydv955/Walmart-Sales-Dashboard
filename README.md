
# Walmart Sales Dashboard

This is a Power BI dashboard created to analyze Walmart sales data.

## Features

- Total Sales
- Total Stores
- Holiday Sales
- Sales by Store
- Sales by Temperature
- Fuel Price Analysis
- CPI Analysis

## Tools Used

- Power BI
- Power Query
- DAX
