# Walmart Sales Dashboard

## Project Overview
This Power BI dashboard analyzes Walmart sales data and provides interactive business insights.

## Dashboard Features
- Total Sales
- Store-wise Sales Analysis
- Holiday vs Non-Holiday Sales
- Sales vs Temperature
- Fuel Price Analysis
- CPI Analysis
- Interactive Filters

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
